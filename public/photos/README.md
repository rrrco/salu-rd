# Fotos editoriales

Coloca aquí las tres fotos. El sitio ya reserva el espacio de cada una, así que
al agregar el archivo con el nombre exacto la foto aparece sin ningún cambio de
código y sin saltos de layout.

| Archivo | Proporción | Qué debe mostrar |
|---|---|---|
| `hero.jpg` | 4:5 vertical | Personal de clínica manipulando un producto SALU, con un animal presente y el entorno visible. Es la foto de confianza. |
| `animal.jpg` | 21:9 horizontal | Un perro sano, tomada en horizontal, con espacio limpio en el tercio izquierdo para el texto que va encima. |
| `delivery.jpg` | 4:3 | Cajas de producto en su entorno real, o una entrega en curso. |

**No hace falta recortar el fondo.** El sistema aplica un tinte teal y una ligera
desaturación a las tres, de modo que fotos de distintas fuentes y con distinta
iluminación se lean como un mismo conjunto. Los fondos suman.

Formato: JPG o WebP. Ancho mínimo recomendado 1600px para `hero.jpg` y
`delivery.jpg`, 2400px para `animal.jpg`.
